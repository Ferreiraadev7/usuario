API REST para gerenciamento de usuários desenvolvida com Java e Spring Boot, com foco em autenticação, autorização e organização de uma aplicação Back-end.

• Implementei autenticação e autorização utilizando Spring Security e JWT.
• Desenvolvi endpoints REST seguindo boas práticas HTTP.
• Utilizei DTOs para separar o modelo da API das entidades de persistência.
• Implementei tratamento global de exceções.
• Estruturei a aplicação seguindo princípios de Clean Architecture.
• Utilizei PostgreSQL e JPA/Hibernate para persistência dos dados.
• Documentei os endpoints utilizando Swagger/OpenAPI.
• UtilizeI Docker para padronizar o ambiente de desenvolvimento.

Stack: Java 21, Spring Boot, Spring Security, JWT, JPA/Hibernate, PostgreSQL, Docker, Swagger/OpenAPI.
